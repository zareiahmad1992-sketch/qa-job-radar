# QA Job Radar

This bot scans public QA job sources and sends new matches directly to Telegram.

Current scope:
- Armenia / Yerevan on-site roles from Staff.am
- Europe-friendly remote roles from public remote job sources

The Telegram token is not stored in this repository. Add it as a GitHub Actions secret named `TELEGRAM_BOT_TOKEN`. Add the chat ID as `TELEGRAM_CHAT_ID`.
